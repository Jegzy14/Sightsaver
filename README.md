# KBDN website concept

An independent, unaffiliated portfolio prototype for the Kenya Business and Disability Network. It is not an official KBDN or Sightsavers project. All resource, event and membership information is illustrative and should not be treated as official network content.

## Run locally

Open `index.html` in a current browser. The prototype uses plain HTML, CSS and JavaScript and needs no build step or package installation. Google Fonts and the hero photograph load from external services; the page falls back to system fonts if the fonts are unavailable.

## What to explore

- Responsive navigation with a keyboard-operable mobile menu.
- Resource search and topic filters with a live result count and a clear-filters action.
- Sample event previews in a keyboard-accessible dialog.
- A membership enquiry demo with native required-field and email validation. Submitting it only displays a local confirmation: no details are sent, stored or followed up.

## UX and accessibility decisions

The page prioritises plain-language navigation, a clear journey from introduction to resources, events and membership, and visible cues that distinguish sample content from confirmed information. It uses semantic landmarks, a skip link, explicit form labels, descriptive image text, visible focus styles, sufficient contrast, keyboard-operable controls, live feedback and reduced-motion support. Layouts adapt for small screens without horizontal scrolling.

This is a WCAG 2.2 AA-informed concept, not a claim of formal conformance. The remote photograph is illustrative; replace it with appropriately licensed, locally managed imagery before production. Content, contact details, membership terms and real event registrations would need confirmation from KBDN.
